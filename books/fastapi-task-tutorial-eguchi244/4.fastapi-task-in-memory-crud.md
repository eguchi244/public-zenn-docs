# インメモリでCRUDを作る
第4章では、データベースはまだ使わず、Python のリストをデータの置き場所にして、タスクの作成・一覧・1件取得を作ります（Phase 2）。

# 今回の目標物
- `POST /tasks` でタスクを作成すると、サーバーが振った `id` と作成日時が付いて返ってくる
- `GET /tasks` で作成したタスクの一覧、`GET /tasks/{task_id}` で1件が返る
- 存在しない ID を指定すると 404 が返る

完成すると、Swagger UI から次のようにタスクを作成できます。送ったのは `title` だけですが、Code が 201 で、サーバーが振った `id: 1` と、記録した `created_at` が付いて返ってきます。

![](/images/fastapi-task-tutorial-eguchi244/4.fastapi-task-in-memory-crud/2026-10-15-21-40-55.png =650x)

# ①Pydanticモデルでデータの形を宣言する
`main.py` を、次の内容に書き換えます。まずはファイルの前半です。

```python:main.py
"""
タスク管理API（FastAPI + SQLAlchemy + SQLite）
"""
from datetime import datetime, timezone

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

# ==========================================
# Pydanticモデル
# ==========================================

class TaskCreate(BaseModel):
    """タスク作成時のリクエストモデル"""
    title: str
    completed: bool = False

class Task(BaseModel):
    """タスク情報のレスポンスモデル"""
    id: int
    title: str
    completed: bool
    created_at: datetime

# ==========================================
# インメモリのデータ置き場（Phase 4 でDBに置き換える）
# ==========================================

tasks: list[Task] = []
next_id: int = 1
```

## Pydantic は「型を宣言すると確かめてくれる」
`BaseModel` を継承したクラスに `title: str` のように「項目名: 型」を並べると、それがデータの形の宣言になります。FastAPI は、届いた JSON がこの形に合っているかを自動で確かめ、合わなければ **422 Unprocessable Entity** を返します。たとえば `title` に `null` を送ると、`str` ではないので弾かれます。

## 「入力の形」と「出力の形」を分ける
| モデル | 役割 | 項目 |
|------|------|------|
| `TaskCreate` | クライアントが**送ってくる**形 | `title`・`completed` |
| `Task` | サーバーが**返す**形 | `id`・`title`・`completed`・`created_at` |

`TaskCreate` に `id` と `created_at` が無いのは、どちらもサーバー側で決める値だからです。この分け方は、入門06でデータベースに切り替えた後もそのまま使います。

## 必須の項目と省略できる項目
- `title: str` には `=` の初期値がありません。そのため**必須**で、`title` を送らなかった場合は 422 になります
- `completed: bool = False` には初期値があるので**省略できます**。省略すると `False` になります

:::message
`title: str` だけでは、空文字 `""` は「文字列」なので受け付けてしまいます。空文字を弾く設定は、入門05で `Field` を使って足します。
:::

## インメモリのデータ置き場
`tasks` は作成したタスクを入れておくリスト、`next_id` は次に振る ID です。どちらもサーバーのメモリ上にあるだけなので、サーバーを止めると消えます（インメモリ）。入門06でデータベースに置き換えます。

# ②作成（POST）と一覧（GET）を実装する
`main.py` の後半に、エンドポイントを書きます。

```python:main.py
# ==========================================
# エンドポイント
# ==========================================

app = FastAPI(title="タスク管理API", version="1.0.0")

@app.get("/tasks", response_model=list[Task])
def read_tasks():
    """
    タスク一覧を取得

    Returns:
    - タスク一覧（JSON配列）
    """
    return tasks

@app.post("/tasks", response_model=Task, status_code=201)
def create_task(payload: TaskCreate):
    """
    タスクを新規作成

    Args:
    - payload: 検証済みの入力（不正な入力は422）

    Returns:
    - 登録したタスク（201）
    """
    global next_id
    task = Task(
        id=next_id,
        title=payload.title,
        completed=payload.completed,
        created_at=datetime.now(timezone.utc),
    )
    next_id += 1
    tasks.append(task)
    return task
```

`POST /tasks` にリクエストが届くと、次の順に処理が進みます。

1. FastAPI が、届いた JSON を `TaskCreate` の形かどうか確かめる。違えば 422 を返して終わり（`create_task` は呼ばれない）
2. 確かめた結果を `payload` に入れて `create_task` を呼ぶ
3. `next_id` と現在時刻（UTC）を足して `Task` を作り、`next_id` を1つ進め、`tasks` に追加する
4. 作った `Task` を返す。FastAPI が JSON にして、ステータス 201 で返す

**リクエストボディは「引数に型を書くだけ」で受け取れる:** `payload: TaskCreate` と書くと、FastAPI がリクエストの JSON を読み取り、確かめたうえで `TaskCreate` として渡してくれます。JSON を自分で読み解く処理も、項目があるかどうかのチェックも要りません。

**`status_code=201`:** 「作成に成功した」ことを表すステータスコードは `201 Created` です。既定の 200 のままでも動きますが、REST API の慣習に合わせます。

**`response_model` ― 返す形の宣言:** `response_model=list[Task]` は「`Task` の配列を返す」という宣言です。返すデータがこの形に合うように整えられ、Swagger UI にも返すデータの形が載ります。

**`global next_id`:** 関数の中で、関数の外にある変数 `next_id` を書き換えるための宣言です。書かないと、関数の中だけの別の変数として扱われてエラーになります。

## Swagger UI で作成してみる
`POST /tasks` を開き、「Try it out」で Request body に次の JSON を入れて「Execute」を押します。

```json
{"title": "買い物"}
```

冒頭の「今回の目標物」の画面のように、201 で `id` と `created_at` が付いたタスクが返ってきます。`completed` は省略したので初期値の `false` です。

# ③1件取得（GET /tasks/{task_id}）と404
`create_task` の下に、1件取得のエンドポイントを追記します。

```python:main.py
@app.get("/tasks/{task_id}", response_model=Task)
def read_task(task_id: int):
    """
    タスク１件を取得

    Args:
    - task_id: 取得対象のタスクID

    Returns:
    - タスク1件（JSON）

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")
```

`tasks` を先頭から順に見て、`id` が一致するものがあれば返します。最後まで見つからなければ、`HTTPException` で 404 を返します。

**パスパラメータ:** URL の `{task_id}` の部分が、引数 `task_id: int` に入ります。`/tasks/1` なら `task_id` は `1` です。`int` と宣言しているので、`/tasks/abc` のような数字でないアクセスは、FastAPI が**自動で 422** にしてくれます。

**「無い」ことは例外で伝える:** 見つからない場合に `None` や空の辞書を返すのではなく、`HTTPException(404)` を送り出します。HTTP の決まり（404 = 指定されたものが存在しない）に乗せるのが REST API の流儀です。API を使う側は、ステータスコードを見るだけで「無かった」と分かります。

`GET /tasks/{task_id}` で、存在しない `999` を指定して実行した結果です。Code が 404 になり、`detail` に `HTTPException` で渡したメッセージが入っています。

# ④動きを追いかけてみる
サーバーを起動したばかりの状態で、「2件作成して、1件目を取得する」と何が起きるかを追ってみます。

1. **起動** → `tasks` は空のリスト、`next_id` は `1`
2. **`POST /tasks` に `{"title": "買い物"}`** → `create_task` が `id=1` のタスクを作る → `tasks` が1件、`next_id` が `2` になる → 201 で返す
3. **`POST /tasks` に `{"title": "掃除", "completed": true}`** → `id=2` のタスクができる → `tasks` が2件、`next_id` が `3` になる
4. **`GET /tasks/1`** → `read_task` が `tasks` を順に見て、`id` が `1` のタスクを返す
5. **サーバーを止めて起動し直す** → `main.py` が最初から実行され、`tasks` は空、`next_id` は `1` に戻る。作ったタスクは消える

5 がインメモリの限界です。入門06でデータベースに切り替えて解決します。

# ⑤動作確認
Swagger UI（`/docs`）で、次の動作ができれば、この章は完了です。

- [✔] `POST /tasks` に `{"title": "買い物"}` → 201 で `id: 1`・`created_at` 付きの JSON が返る
- [✔] もう1件 `{"title": "掃除", "completed": true}` を作成 → `id: 2` になる（自動で番号が振られる）
- [✔] `GET /tasks` → 2件の配列が返る
- [✔] `GET /tasks/1` → 1件目だけが返る
- [✔] `GET /tasks/999` → 404 `{"detail": "Task not found"}`
- [✔] サーバーを再起動（`Ctrl + C` → もう一度 `uvicorn main:app --reload`）すると全件消える（インメモリの限界。入門06で解決します）

# まとめ
ここまでの内容で、タスクの作成・一覧・1件取得ができるようになりました。

- Pydantic のモデルでデータの形を宣言すると、入力のチェックを FastAPI が自動で行う
- 入力用（`TaskCreate`）と出力用（`Task`）でモデルを分ける
- `response_model` と `status_code` で、返す形とステータスコードを宣言する
- パスパラメータで ID を受け取り、見つからなければ `HTTPException` で 404 を返す

など、API の基本の形を学ばれたと思います。
