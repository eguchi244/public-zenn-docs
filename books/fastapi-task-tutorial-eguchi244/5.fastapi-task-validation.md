# バリデーションと部分更新
第5章では、入力のルールを強化し、更新（PUT）・削除（DELETE）・一覧の絞り込みを追加します（Phase 3）。これで、データの置き場所はリストのままですが、API の形は完成します。

# 今回の目標物
- 空のタイトルや 256 文字以上のタイトルを送ると 422 が返る
- `PUT /tasks/{task_id}` で、送った項目だけが書き換わる（部分更新）
- `DELETE /tasks/{task_id}` で削除できる
- `GET /tasks?completed=true` で完了したタスクだけが返る

完成すると、`PUT` で次のように部分更新ができます。`{"completed": true}` だけを送ったので、`title` は「買い物」のまま、`completed` だけが `true` に変わっています。

![](/images/fastapi-task-tutorial-eguchi244/5.fastapi-task-validation/2026-10-15-21-40-56.png =650x)

# ①Fieldで入力ルールを強化する
Pydantic モデルを、次のように書き換えます。import に `Field` を追加し、更新用の `TaskUpdate` を新しく足します。

```python:main.py
from pydantic import BaseModel, Field


class TaskCreate(BaseModel):
    """タスク作成時のリクエストモデル"""
    title: str = Field(..., min_length=1, max_length=255)
    completed: bool = False


class TaskUpdate(BaseModel):
    """タスク更新時のリクエストモデル"""
    title: str | None = Field(None, min_length=1, max_length=255)
    completed: bool | None = None
```

## Field(..., min_length=1) ― 必須で空文字も不可
`Field` は、項目に細かいルールを付けるための書き方です。

| 書き方 | 意味 |
|------|------|
| 第1引数の `...` | 必須（初期値が無い）。`...` は Python の Ellipsis という特別な値 |
| `min_length=1` | 1文字以上。空文字 `""` を弾く |
| `max_length=255` | 255文字以内 |

違反したリクエストには、FastAPI が **422 Unprocessable Entity** と「どの項目がなぜダメか」を示す JSON を自動で返します。自分で if 文を書いてチェックする必要はありません。

`POST /tasks` に空のタイトル `{"title": ""}` を送った結果です。Response body の `loc` が問題の場所（`body` の `title`）、`type` の `string_too_short` と `ctx` の `min_length: 1` が違反したルールを示しています。

![](/images/fastapi-task-tutorial-eguchi244/5.fastapi-task-validation/2026-10-15-21-40-55.png =650x)

## TaskUpdate ― 全項目を省略できる「部分更新」用のモデル
`str | None = Field(None, ...)` は「文字列か `None`。送られてこなければ `None`」という意味です。`completed: bool | None = None` も同じです。

全項目を省略できるので、`{"completed": true}` だけを送って完了の状態だけを変える、という使い方ができます。`title` を送る場合は、作成時と同じルール（1〜255文字）で確かめられます。

# ②404の処理をget_taskにまとめる
これから作る PUT と DELETE も、1件取得と同じく「ID でタスクを探し、無ければ 404」が必要です。同じ処理を3か所に書かないよう、関数にまとめます。インメモリのデータ置き場の下に追記します。

```python:main.py
# ==========================================
# ヘルパー関数
# ==========================================

def get_task(task_id: int) -> Task:
    """
    指定されたIDのタスクを取得する

    Args:
        task_id : 検索対象のタスクID

    Returns:
        見つかったタスクオブジェクト

    Raises:
        HTTPException : タスクが見つからない場合（404 Task Not Found）
    """
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")
```

中身は入門04の `read_task` に書いたものと同じです。`read_task` も `get_task` を使うように書き換えます。

```python:main.py
@app.get("/tasks/{task_id}", response_model=Task)
def read_task(task_id: int):
    """
    タスク１件を取得

    Args:
    - task_id: 取得対象のタスクID

    Returns:
    - タスク1件（JSON）

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    return get_task(task_id)
```

`get_task` の中で `HTTPException` が送り出されると、呼び出した `read_task` の残りの処理は実行されず、そのまま 404 が返ります。そのため呼び出す側は「見つかった場合」のことだけを書けば済みます。

**同じコードを2回書きそうになったら関数にまとめる。** API でも同じです。

# ③更新（PUT）と削除（DELETE）を実装する
`create_task` の下に追記します。

```python:main.py
@app.put("/tasks/{task_id}", response_model=Task)
def update_task(task_id: int, payload: TaskUpdate):
    """
    タスクを更新（渡された項目のみ反映する部分更新）

    Args:
    - task_id: 更新対象のタスクID
    - payload: 検証済みの入力（None の項目は変更しない。不正な入力は422）

    Returns:
    - 更新したタスク

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    task = get_task(task_id)

    if payload.title is not None:
        task.title = payload.title
    if payload.completed is not None:
        task.completed = payload.completed

    return task

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    """
    タスクを削除

    Args:
    - task_id: 削除対象のタスクID

    Returns:
    - 削除できたことを示す {"ok": true}

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    task = get_task(task_id)
    tasks.remove(task)
    return {"ok": True}
```

**PUT ― 送られた項目だけを書き換える:** `get_task` で対象を探し（無ければ 404）、`payload` の項目が `None` でないもの、つまり**送られてきた項目だけ**を書き換えます。送られなかった項目は `None` なので、元の値のまま残ります。

**DELETE ― 探してから取り除く:** `get_task` で対象を探し（無ければ 404）、`tasks.remove(task)` でリストから取り除きます。返すのは、成功したことを示す `{"ok": True}` です。FastAPI が JSON の `{"ok": true}` に変換します。

:::message
DELETE には `response_model` を付けていません。`Task` を返さず、決まった1項目の辞書を返すだけだからです。そのため Swagger UI には、返すデータの形が表示されません。
:::

# ④一覧の絞り込み（クエリパラメータ）
`read_tasks` を、`completed` で絞り込めるように書き換えます。

```python:main.py
@app.get("/tasks", response_model=list[Task])
def read_tasks(completed: bool | None = None):
    """
    タスク一覧（?completed=true/false で絞り込み可）

    Args:
    - completed: 完了状態での絞り込み（省略時は全件）

    Returns:
    - タスク一覧（JSON配列）
    """

    # 絞り込みがない場合（?completed=None, 省略）はすべてのタスクを返す
    if completed is None:
        return tasks

    # 絞り込みがある場合（?completed=true/false）はcompletedが一致するものだけ返す
    return [task for task in tasks if task.completed == completed]
```

**クエリパラメータ:** URL のパス（`{task_id}` のような部分）に含まれない引数は、自動で**クエリパラメータ**になります。URL の `?` の後ろに `/tasks?completed=true` のように付けて渡す値です。`= None` の初期値があるので省略でき、省略すると全件を返します。

**リスト内包表記:** `[task for task in tasks if task.completed == completed]` は、「`tasks` の中から `completed` が一致するものだけを集めたリスト」を1行で作る書き方です。

| リクエスト | `completed` の値 | 返るもの |
|------|------|------|
| `GET /tasks` | `None` | 全件 |
| `GET /tasks?completed=true` | `True` | 完了したタスクだけ |
| `GET /tasks?completed=false` | `False` | 未完了のタスクだけ |

Swagger UI では、`GET /tasks` を開いて「Try it out」を押すと `completed` の選択欄が出ます。

:::details main.py の全体コード
```python:main.py
"""
タスク管理API（FastAPI + SQLAlchemy + SQLite）
"""
from datetime import datetime, timezone

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

# ==========================================
# Pydanticモデル
# ==========================================

class TaskCreate(BaseModel):
    """タスク作成時のリクエストモデル"""
    title: str = Field(..., min_length=1, max_length=255)
    completed: bool = False

class TaskUpdate(BaseModel):
    """タスク更新時のリクエストモデル"""
    title: str | None = Field(None, min_length=1, max_length=255)
    completed: bool | None = None

class Task(BaseModel):
    """タスク情報のレスポンスモデル"""
    id: int
    title: str
    completed: bool
    created_at: datetime

# ==========================================
# インメモリのデータ置き場（Phase 4 でDBに置き換える）
# ==========================================

tasks: list[Task] = []
next_id: int = 1

# ==========================================
# ヘルパー関数
# ==========================================

def get_task(task_id: int) -> Task:
    """
    指定されたIDのタスクを取得する

    Args:
        task_id : 検索対象のタスクID

    Returns:
        見つかったタスクオブジェクト

    Raises:
        HTTPException : タスクが見つからない場合（404 Task Not Found）
    """
    for task in tasks:
        if task.id == task_id:
            return task
    raise HTTPException(status_code=404, detail="Task not found")

# ==========================================
# エンドポイント
# ==========================================

app = FastAPI(title="タスク管理API", version="1.0.0")

@app.get("/tasks", response_model=list[Task])
def read_tasks(completed: bool | None = None):
    """
    タスク一覧（?completed=true/false で絞り込み可）

    Args:
    - completed: 完了状態での絞り込み（省略時は全件）

    Returns:
    - タスク一覧（JSON配列）
    """

    # 絞り込みがない場合（?completed=None, 省略）はすべてのタスクを返す
    if completed is None:
        return tasks

    # 絞り込みがある場合（?completed=true/false）はcompletedが一致するものだけ返す
    return [task for task in tasks if task.completed == completed]

@app.get("/tasks/{task_id}", response_model=Task)
def read_task(task_id: int):
    """
    タスク１件を取得

    Args:
    - task_id: 取得対象のタスクID

    Returns:
    - タスク1件（JSON）

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    return get_task(task_id)

@app.post("/tasks", response_model=Task, status_code=201)
def create_task(payload: TaskCreate):
    """
    タスクを新規作成

    Args:
    - payload: 検証済みの入力（不正な入力は422）

    Returns:
    - 登録したタスク（201）
    """
    global next_id
    task = Task(
        id=next_id,
        title=payload.title,
        completed=payload.completed,
        created_at=datetime.now(timezone.utc),
    )
    next_id += 1
    tasks.append(task)
    return task

@app.put("/tasks/{task_id}", response_model=Task)
def update_task(task_id: int, payload: TaskUpdate):
    """
    タスクを更新（渡された項目のみ反映する部分更新）

    Args:
    - task_id: 更新対象のタスクID
    - payload: 検証済みの入力（None の項目は変更しない。不正な入力は422）

    Returns:
    - 更新したタスク

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    task = get_task(task_id)

    if payload.title is not None:
        task.title = payload.title
    if payload.completed is not None:
        task.completed = payload.completed

    return task

@app.delete("/tasks/{task_id}")
def delete_task(task_id: int):
    """
    タスクを削除

    Args:
    - task_id: 削除対象のタスクID

    Returns:
    - 削除できたことを示す {"ok": true}

    Raises:
    - HTTPException: タスクが見つからない場合は404
    """
    task = get_task(task_id)
    tasks.remove(task)
    return {"ok": True}
```
:::

# ⑤動きを追いかけてみる
「買い物」を1件作成した状態で、次のリクエストを順に送ると何が起きるかを追ってみます。

1. **`PUT /tasks/1` に `{"completed": true}`** → FastAPI が `TaskUpdate` として確かめる（`title` は省略なので `None`）→ `update_task` が `get_task(1)` で「買い物」を見つける → `completed` だけを `True` にする → 200 で返す
2. **`PUT /tasks/1` に `{"title": ""}`** → `TaskUpdate` の `min_length=1` に違反 → FastAPI が 422 を返す。`update_task` は呼ばれないので、タスクは変わらない
3. **`DELETE /tasks/1`** → `get_task(1)` で見つける → `tasks` から取り除く → `{"ok": true}`
4. **もう一度 `DELETE /tasks/1`** → `get_task(1)` が見つけられず `HTTPException` を送り出す → 404

2 のように、入力のチェックは**関数が呼ばれる前に** FastAPI が済ませています。関数の中には、正しい入力が来たときの処理だけを書けばよいのです。

# ⑥動作確認
Swagger UI（`/docs`）で、次の動作ができれば、この章は完了です。

- [✔] `POST /tasks` に `{"title": ""}` → 422 が返り、`min_length` 違反であることが JSON で示される
- [✔] `{"title": 123}` のような型違いも 422 になる
- [✔] `PUT /tasks/1` に `{"completed": true}` だけを送る → タイトルは変わらず完了だけ更新される（部分更新）
- [✔] `PUT /tasks/999` → 404
- [✔] `GET /tasks?completed=true` → 完了したタスクだけが返る
- [✔] `DELETE /tasks/1` → `{"ok": true}`。もう一度 `DELETE /tasks/1` → 404

:::message
サーバーを再起動するとタスクが消えるので、確認の前に `POST /tasks` でタスクを作り直してください。
:::

# まとめ
ここまでの内容で、API の形が完成しました。

- `Field` で入力のルールを宣言すると、違反は FastAPI が自動で 422 にする
- 全項目を省略できる `TaskUpdate` で、送った項目だけを書き換える部分更新を作る
- 「探す → 無ければ 404」を `get_task` にまとめる
- パスに含まれない引数はクエリパラメータになる

など、入力から API を守るための技法を学ばれたと思います。

ただし、データの置き場所はまだリストなので、サーバーを再起動すると全部消えてしまいます。次の入門06では、データの置き場所を SQLite のデータベースに差し替えます。
