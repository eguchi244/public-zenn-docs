# フィルタリングと件数表示
第5章では、「すべて / 未完了 / 完了済み」の絞り込みと、フッターの件数表示を実装します（Phase 3）。

# 今回の目標物
- タブを押すと、一覧がそのタブの条件で絞り込まれる
- 選択中のタブの見た目が変わる
- フッターに「残り N 件 / 全 M 件」が表示される

完成すると次の画面になります。3件のうち1件を完了にして「未完了」タブを選んだところです。一覧は2件に減っていますが、件数は「残り 2 件 / 全 3 件」のままです。

![](/images/js-task-tutorial-eguchi244/5.js-task-filter/2026-10-14-20-33-45.png =650x)

この章で増える流れは次の1本です。タブのクリックでは `filter` を書き換えるだけで、絞り込みの実際の処理は `render()` が行います。

```
[タブをクリック] → handleFilterClick()
  → 押されたタブの data-filter を読む
  → filter を書き換える   ← 状態を変える
  → render()              ← 絞り込み・件数・タブの強調をまとめて描き直す
```

# ①render() を絞り込みに対応させる
`render()` を、次の完成形に書き換えます。

```js:script.js
/**
 * 現在の状態（tasks, filter）に基づいて画面を再描画する
 *
 * 以下の処理をすべて実行します：
 * 1. 選択中のフィルター（all/active/completed）に応じたタスクの絞り込みとリスト描画
 * 2. フッター（残り件数 / 総件数）のテキスト更新
 * 3. フィルターボタンのアクティブ状態（CSSクラス）の切り替え
 */
function render() {
  // フィルタに応じた絞り込みでtasks配列を作り直す
  const visibleTasks = tasks.filter((task) => {
    if (filter === 'active') return !task.completed;
    if (filter === 'completed') return task.completed;
    return true;
  });

  // タスクリストの再描画（空にしてから生成し直す）
  taskList.innerHTML = '';
  visibleTasks.forEach((task) => {
    taskList.appendChild(createTaskElement(task));
  });

  // フッター（残り件数 / 総件数）
  const remaining = tasks.filter((task) => !task.completed).length;
  taskCount.textContent = `残り ${remaining} 件 / 全 ${tasks.length} 件`;

  // フィルタータブのアクティブ状態（CSSクラス）の切り替え
  filterButtons.forEach((btn) => {
    btn.classList.toggle('active', btn.dataset.filter === filter);
  });
}
```

`render()` の仕事が3つに増えました。上から順に見ていきます。

## (1) 表示するタスクを絞り込む
`tasks.filter(...)` で、`filter` の値に応じて表示するタスクだけを集めた `visibleTasks` を作ります。

| `filter` の値 | 残すタスク |
|------|------|
| `'active'`（未完了） | `completed` が `false` のもの（`!task.completed`） |
| `'completed'`（完了済み） | `completed` が `true` のもの |
| `'all'`（すべて） | 全部（`return true`） |

一覧に描くのは `tasks` ではなく `visibleTasks` です。`tasks` そのものは書き換えていないので、タブを「すべて」に戻せば全件が表示されます。

## (2) フッターの件数を出す
残り件数は「未完了のタスクの数」なので、`tasks` から未完了のものを集めて `.length` で数えます。全件数は `tasks.length` です。

件数は `visibleTasks` ではなく `tasks` から数えます。そのため、どのタブを選んでいても件数は変わりません。

**テンプレートリテラル:** `` `残り ${remaining} 件 / 全 ${tasks.length} 件` `` のように、文字列全体をバッククォート（`` ` ``）で囲むと、`${}` の中に変数や計算の結果を埋め込めます。

## (3) 選択中のタブを強調する
`classList.toggle(クラス名, 条件)` は、条件が `true` ならクラスを付け、`false` なら外します。3つのタブそれぞれについて「自分の `data-filter` が今の `filter` と同じか」を条件にしているので、選択中のタブにだけ `active` クラスが付きます。if 文を書かずに、全部のタブを1行で正しい状態にできます。

## 「派生値」は状態に持たない
絞り込んだ一覧（`visibleTasks`）も残り件数（`remaining`）も、変数として保存しておかず、`render()` のたびに `tasks` と `filter` から**計算し直しています**。

もし `remaining` を状態として持っておくと、タスクを追加・削除・完了にするたびに `remaining` も忘れずに更新しなければなりません。1か所でも更新を忘れれば、件数と一覧が食い違います。

**状態は最小限（`tasks` と `filter`）だけを持ち、そこから計算できるもの（派生値）は描画のときに計算する。** 状態を扱うときの大原則です。

# ②フィルタータブのイベントをつなぐ
タブがクリックされたときのイベントハンドラーを、`handleTaskListClick` の下に追記します。

```js:script.js
/**
 * フィルターボタンのクリックイベントを処理する
 *
 * @param {MouseEvent} event - クリックイベントのオブジェクト
 */
function handleFilterClick(event) {
  // クリックされたボタンの data-filter を取得
  const nextFilter = event.target.dataset.filter;

  // data-filterが取得できない場合は何もしない
  if (!nextFilter) return;

  // 状態（filter）を更新
  filter = nextFilter;

  // 画面を再描画する
  render();
}
```

イベントリスナーの登録も追記します。

```js:script.js
// --- フィルターボタンの切り替え（各ボタンに個別バインド） ---
filterButtons.forEach((btn) => {
  btn.addEventListener('click', handleFilterClick);
});
```

**状態だけを変える:** タブのクリックでやることは、`filter` を書き換えて `render()` を呼ぶことだけです。絞り込みもタブの強調も `render()` の中にあるので、イベント側は状態を変えるだけで済みます。

## 個別バインドとイベントデリゲーションの使い分け
ここでは、入門04のタスク一覧と違って**3つのタブそれぞれに**リスナーを付けています（個別バインド）。`forEach` で1つずつ `addEventListener` を呼ぶ書き方です。

| | タスク一覧（入門04） | フィルタータブ（入門05） |
|---|---|---|
| 要素の数 | タスクの件数だけ増減する | 3個で固定 |
| `render()` で作り直すか | 作り直す | 作り直さない（HTML に書いたまま） |
| 選んだ方法 | イベントデリゲーション | 個別バインド |

イベントデリゲーションが効くのは「要素が増えたり減ったり、作り直されたりする」場合です。数が決まっていて作り直さない要素なら、個別にリスナーを付けるほうが素直です。

「完了済み」タブに切り替えると、完了にした1件だけが表示されます。選んだタブの見た目が変わるのは、`active` クラスが付け替わったためです。

![](/images/js-task-tutorial-eguchi244/5.js-task-filter/2026-10-14-20-33-46.png =650x)

:::details script.js の全体コード
```js:script.js
/* ==========================================
 * タスク管理アプリ（Vanilla JS）
 * 状態管理・DOM描画・localStorage永続化
 * ========================================*/

// ==========================================
// 型定義
// ==========================================

/**
 * タスク1件（localStorage に保存する形）
 *
 * @typedef {Object} Task
 * @property {string} id - タスクのID（crypto.randomUUID() で作るUUID）
 * @property {string} title - タスクの内容
 * @property {boolean} completed - 完了していれば true
 * @property {string} createdAt - 作成日時（ISO 8601形式の文字列）
 */

// ==========================================
// DOM要素
// ==========================================
/** タスクの入力フォーム */
const taskForm      = document.getElementById('taskForm');
/** タスクの入力欄 */
const taskInput     = document.getElementById('taskInput');
/** 絞り込みのボタン（すべて・未完了・完了済み） */
const filterButtons = document.querySelectorAll('.filter');
/** タスクの一覧を表示する要素 */
const taskList      = document.getElementById('taskList');
/** 残り件数と総件数を表示する要素 */
const taskCount     = document.getElementById('taskCount');

// ==========================================
// 状態変数
// NOTE: 単一の真実のソース（Single Source of Truth）
// ==========================================
/**
 * 全タスクの一覧（画面の表示と保存の元になる）
 *
 * @type {Task[]}
 */
let tasks  = [];    // タスク配列
/** 選択中の絞り込み（'all' | 'active' | 'completed'） */
let filter = 'all'; // 'all' | 'active' | 'completed'

// ==========================================
// localStorage Key
// ==========================================
/** localStorage に保存するときのキー */
const STORAGE_KEY = 'tasks';

// ==========================================
// タスク操作
// ==========================================

/**
 * 新しいタスクを作成してtasks配列に追加する
 *
 * @param {string} title - タスクのタイトル
 */
function addTask(title) {
  tasks.push({
    id: crypto.randomUUID(),
    title,
    completed: false,
    createdAt: new Date().toISOString(),
  });
}

/**
 * 指定ID以外のタスクでtasks配列を作り直す
 *
 * NOTE: 指定IDのタスクを削除すると同義です
 * @param {string} id - タスクのUUID
 */
function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
}

/**
 * タスクの完了状態を反転して更新する
 *
 * @param {string} id - タスクのUUID
 */
function toggleTask(id) {
  // 指定IDのタスクを取得
  const task = tasks.find((t) => t.id === id);

  // タスクの完了状態を反転する
  // NOTE: undefined対策 - タスクを取得できない時は状態更新しない
  if (task) {
    task.completed = !task.completed;
  }
}

// ==========================================
// DOM 描画
// ==========================================

/**
 * タスクリストのli要素を作成する
 *
 * @param {Task} task - タスク
 * @returns {HTMLLIElement}　li要素のタスクリスト
 */
function createTaskElement(task) {
  // li要素を作成する
  const li = document.createElement('li');
  li.className = task.completed ? 'task-item completed' : 'task-item';

  // checkbox要素を作成する
  const checkbox = document.createElement('input');
  checkbox.type = 'checkbox';
  checkbox.checked = task.completed;
  checkbox.dataset.id = task.id;
  checkbox.dataset.action = 'toggle';

  // タイトルのspan要素を作成する
  const title = document.createElement('span');
  title.className = 'task-title';
  title.textContent = task.title; // XSS対策(textContent使用)

  // 削除用のbtn要素を作成する
  const deleteBtn = document.createElement('button');
  deleteBtn.type = 'button';
  deleteBtn.className = 'btn btn-delete';
  deleteBtn.textContent = '削除';
  deleteBtn.dataset.id = task.id;
  deleteBtn.dataset.action = 'delete';

  // li要素に各要素をまとめて追加する
  li.append(checkbox, title, deleteBtn);
  return li;
}

/**
 * 現在の状態（tasks, filter）に基づいて画面を再描画する
 *
 * 以下の処理をすべて実行します：
 * 1. 選択中のフィルター（all/active/completed）に応じたタスクの絞り込みとリスト描画
 * 2. フッター（残り件数 / 総件数）のテキスト更新
 * 3. フィルターボタンのアクティブ状態（CSSクラス）の切り替え
 */
function render() {
  // フィルタに応じた絞り込みでtasks配列を作り直す
  const visibleTasks = tasks.filter((task) => {
    if (filter === 'active') return !task.completed;
    if (filter === 'completed') return task.completed;
    return true;
  });

  // タスクリストの再描画（空にしてから生成し直す）
  taskList.innerHTML = '';
  visibleTasks.forEach((task) => {
    taskList.appendChild(createTaskElement(task));
  });

  // フッター（残り件数 / 総件数）
  const remaining = tasks.filter((task) => !task.completed).length;
  taskCount.textContent = `残り ${remaining} 件 / 全 ${tasks.length} 件`;

  // フィルタータブのアクティブ状態（CSSクラス）の切り替え
  filterButtons.forEach((btn) => {
    btn.classList.toggle('active', btn.dataset.filter === filter);
  });
}

// ==========================================
// イベントハンドラー
// ==========================================

/**
 * タスク入力欄の送信イベントを処理する
 *
 * @param {SubmitEvent} event - フォーム送信のイベントオブジェクト
 */
function handleTaskSubmit(event) {
  // Formの規定動作を止める（SPA用のページリロード対策）
  event.preventDefault();

  // バリデーション
  // NOTE: 前後の空白を除去した結果が空文字なら追加しない
  const title = taskInput.value.trim();
  if (title === '') return;

  // タスクリストを作成して描画する
  addTask(title);
  render();

  // タスク入力欄を空にしてフォーカスする
  taskInput.value = '';
  taskInput.focus();
}

/**
 * タスクリスト内のクリックイベントを処理する（イベント移譲）
 *
 * NOTE: タスクリストの削除・完了切り替えを action に応じて実行する
 * @param {MouseEvent} event - クリックイベントのオブジェクト
 */
function handleTaskListClick(event) {
  // クリックされた要素の data-id と data-action を取得
  const { id, action } = event.target.dataset;

  // idが存在しない場合は何もしない
  if (!id) return;

  // actionに応じた状態更新を実行する
  if (action === 'delete') {
    deleteTask(id);
  } else if (action === 'toggle') {
    toggleTask(id);
  } else {
    return;
  }

  // 画面を再描画する
  render();
}

/**
 * フィルターボタンのクリックイベントを処理する
 *
 * @param {MouseEvent} event - クリックイベントのオブジェクト
 */
function handleFilterClick(event) {
  // クリックされたボタンの data-filter を取得
  const nextFilter = event.target.dataset.filter;

  // data-filterが取得できない場合は何もしない
  if (!nextFilter) return;

  // 状態（filter）を更新
  filter = nextFilter;

  // 画面を再描画する
  render();
}

// ==========================================
// イベントリスナー
// ==========================================

// --- タスク入力欄 ---
taskForm.addEventListener('submit', handleTaskSubmit);

// --- タスクリストの削除・完了切り替え（イベント移譲）---
taskList.addEventListener('click', handleTaskListClick);

// --- フィルターボタンの切り替え（各ボタンに個別バインド） ---
filterButtons.forEach((btn) => {
  btn.addEventListener('click', handleFilterClick);
});

// ==========================================
// 初期描画
// ==========================================
render();
```
:::

# ③動きを追いかけてみる
タスクが3件（うち1件が完了）ある状態で、「未完了」タブを押してから、表示中のタスクにチェックを入れると何が起きるかを追ってみます。

1. **「未完了」タブをクリック** → `handleFilterClick` が呼ばれる → `filter` が `'active'` になる → `render()` が未完了の2件だけを描き、「未完了」タブに `active` クラスを付ける。件数は `tasks` から数えるので「残り 2 件 / 全 3 件」のまま
2. **表示中の1件にチェックを入れる** → 入門04の `handleTaskListClick` → `toggleTask` で `completed` が `true` になる → `render()` が描き直す。このタスクはもう未完了ではないので、**一覧から消える**。件数は「残り 1 件 / 全 3 件」になる

2 で、タスクを一覧から消す処理はどこにも書いていません。「状態が変わったので、`render()` が今の状態どおりに描いた」結果として消えています。

# ④動作確認
次の動作ができれば、この章は完了です。

- [✔] タスクを3件追加し、1件だけ完了にする
- [✔] 「未完了」タブ → 未完了の2件だけが表示される
- [✔] 「完了済み」タブ → 完了の1件だけが表示される
- [✔] 選択中のタブの見た目が変わる（`active` クラス）
- [✔] どのタブにいても、フッターは「残り 2 件 / 全 3 件」のまま（件数は絞り込みの影響を受けない）
- [✔] 「未完了」タブの表示中にチェックを入れると、そのタスクが一覧から消える（未完了ではなくなったため）

# まとめ
ここまでの内容で、絞り込みと件数表示ができるようになりました。

- 絞り込みや件数のような「派生値」は状態に持たず、描画のときに計算する
- `classList.toggle(クラス名, 条件)` で、選択中のタブだけを強調する
- 要素が増減するならイベントデリゲーション、数が決まっているなら個別バインド

など、状態を最小限に保つ考え方を学ばれたと思います。

ただし、このアプリはまだリロードするとタスクが全部消えてしまいます。次の入門06では、`localStorage` にタスクを保存して、リロードしても消えないようにします。
