# はじめに
この書籍は、フレームワークを使わない素の JavaScript（Vanilla JS）で「タスク管理アプリ（ToDo アプリ）」を作ることを目的としています。

タスク管理アプリは、Web アプリの基本となる「データを追加・表示・更新・削除する（CRUD）」がひととおり詰まった題材です。

- 配列でデータを持ち、追加・削除・更新する
- データ（状態）から画面を描き直す
- 増えたり減ったりする要素のクリックを、親要素でまとめて受け取る（イベントデリゲーション）
- ユーザーが入力した文字を安全に表示する（XSS 対策）
- ブラウザにデータを保存して、リロードしても消えないようにする（`localStorage`）

フレームワークを使うと、これらの多くは裏側で自動的に処理されます。最初に素の JavaScript で一度作っておくと、フレームワークが何を肩代わりしているのかが見えるようになります。

:::message
この書籍は、コードを読み慣れていない方でも進められるように書いています。コードは役割ごとに分けて掲載し、それぞれの直後に「何をしているか・なぜ必要か」を説明します。

同じシリーズの「JavaScript入門 - タイマーアプリを作ってみよう!」を先に読んでいると、`addEventListener` や「状態から画面を作る」考え方がすでに身についているので、より楽に進められます。読んでいなくても進められるように書いています。
:::

# ①作るもの
ブラウザ単体で動作するタスク管理アプリです。

画面は次のとおりです。入力欄からタスクを追加し、チェックボックスで完了にすると打ち消し線が付きます。上のタブで「すべて / 未完了 / 完了済み」を絞り込み、下の行に残りの件数が表示されます。リロードしてもタスクは消えません。

![](/images/js-task-tutorial-eguchi244/1.js-task-introduction/2026-10-14-20-33-45.png =650x)

## 機能一覧
### タスク操作
| # | 要件 |
|---|------|
| F-01 | テキスト入力欄にタスク名を入力し、追加ボタンまたは Enter キーでタスクを追加できる |
| F-02 | タスク名が空の場合は追加できない（バリデーション） |
| F-03 | 各タスクにチェックボックスを表示し、クリックで完了/未完了を切り替えられる |
| F-04 | 各タスクに削除ボタンを表示し、クリックで該当タスクを削除できる |
| F-05 | 完了済みタスクは視覚的に区別できる（打ち消し線など） |

### フィルタリング
| # | 要件 |
|---|------|
| F-06 | 「すべて」「未完了」「完了済み」の3種類でタスク一覧を絞り込める |
| F-07 | 現在選択中のフィルターが視覚的に分かる |

### データの保存
| # | 要件 |
|---|------|
| F-08 | タスクの追加・削除・完了状態の変更は `localStorage` に自動保存される |
| F-09 | ページをリロードしても保存済みのタスク一覧が復元される |
| F-10 | `localStorage` の保存データが不正（未保存・壊れた JSON・配列以外）な場合でもアプリは起動でき、空のタスク一覧から開始する |

### 表示
| # | 要件 |
|---|------|
| F-11 | 残りタスク件数（未完了）と総件数をフッターに表示する |

## 非機能要件
| # | 要件 |
|---|------|
| NF-01 | 外部ライブラリ・フレームワーク不使用（Vanilla JS のみ） |
| NF-02 | モバイルブラウザでも操作しやすいレイアウトであること |

# ②学習目標
この書籍を終えると、次のことができるようになります。

- 配列操作（追加・削除・更新）でデータを管理できる
- データ（状態）を変えてから画面を描き直す流れを、フレームワークを使わずに書ける
- イベントデリゲーションで、増減する要素のクリックを1か所で受け取れる
- ユーザー入力を `textContent` で表示し、XSS を防げる
- `localStorage` を使ったデータの保存・読み込みと、壊れたデータへの備えを実装できる

# ③進め方
4つのフェーズに分けて、段階的にタスク管理アプリを完成させます。

| 章 | フェーズ | 内容 | 習得する概念 |
|----|----------|------|------------|
| 入門03 | Phase 1 | タスクの追加と一覧描画 | 状態（配列）→ 画面の描き直し / `submit` イベント |
| 入門04 | Phase 2 | 完了切り替えと削除 | `createElement` / `data-*` 属性 / イベントデリゲーション / XSS 対策 |
| 入門05 | Phase 3 | フィルタリングと件数表示 | 状態から計算する値（派生値）/ タブのアクティブ表示 |
| 入門06 | Phase 4 | localStorage で永続化する | `JSON.stringify` / `JSON.parse` / 壊れたデータへの防御 |

各フェーズで動くものが作れます。フェーズを重ねるごとに機能が増えていきますが、「状態を変える → 画面を描き直す」という形は最後まで変わりません。

コードを書き始める前に、次の入門02で設計（データ・状態・処理の流れ）を確認します。

# ④開発環境
## 技術スタック
| 項目 | 内容 |
|------|------|
| 言語 | HTML5 / CSS3 / JavaScript（ES6+） |
| 実行環境 | ブラウザ（Chrome 最新版を基準） |
| データ保存 | `localStorage`（ブラウザ標準の保存領域） |
| 開発ツール | VS Code + Live Server 拡張 |

外部ライブラリやビルドツールは使いません。ブラウザだけで動作するので、仮想環境やパッケージのインストールも不要です。

## VS Code と Live Server を用意する
VS Code と Live Server 拡張機能を使うと、ファイルを保存するたびにブラウザが自動でリロードされて便利です。Windows の場合は、PowerShell で次のコマンドを実行するとインストールできます。

```powershell:PowerShell
winget install Microsoft.VisualStudioCode
code --install-extension ritwickdey.LiveServer
```

:::message
`code` コマンドが見つからない場合は、VS Code をインストールしたあとにターミナルを開き直してください。
:::

## 作業フォルダを作る
任意の場所に作業フォルダ（例: `js-task`）を作り、VS Code で開きます。この書籍では、このフォルダに次の3つのファイルを作っていきます。

```
js-task/
├── index.html   # マークアップ（画面の構造）
├── style.css    # スタイル（見た目）
└── script.js    # タスクの操作・画面の描画・保存
```

起動するときは、VS Code で `index.html` を右クリック →「Open with Live Server」を選びます。

:::message
`localStorage` はページを開いた場所（オリジン）ごとに保存されます。Live Server で開いた場合と、`index.html` をダブルクリックして直接開いた場合とでは、別々の保存場所になります。入門06で保存を確かめるときは、毎回同じ開き方をしてください。
:::

## CSS について
この書籍は JavaScript の学習に集中するため、CSS は完成版の `style.css` をそのまま使います。下記からダウンロードして、`index.html` と同じフォルダに置いてください。

https://github.com/eguchi244/JS-Task-Tutorial-PJ/blob/main/style.css

:::message
CSS を自分で書きたい場合も、次の2つは必須です。完了したタスクの打ち消し線と、選択中のタブの強調をこのクラスで表しているため、無いと入門04以降の動作確認で見た目の変化が分かりません。

```css:style.css
/* 完了済みタスクの打ち消し線 */
.task-item.completed .task-title {
  text-decoration: line-through;
}

/* 選択中のフィルタータブ */
.filter.active {
  font-weight: bold;
}
```
:::
