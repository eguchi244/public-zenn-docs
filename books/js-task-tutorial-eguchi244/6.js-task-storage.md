# localStorageで永続化する
第6章では、タスクをブラウザに保存して、リロードしても消えないようにします（Phase 4）。これでタスク管理アプリの完成です。

# 今回の目標物
- タスクを追加・完了・削除すると、自動でブラウザに保存される
- リロードしても、タスクと完了の状態がそのまま残る
- 保存データが壊れていても、アプリはエラーにならずに起動する

完成すると、リロードした後も次のようにタスクと完了の状態が残ります。

![](/images/js-task-tutorial-eguchi244/6.js-task-storage/2026-10-14-20-33-45.png =650x)

# ①入門05の問題を体験する
入門05までのアプリでタスクをいくつか追加してから、ページをリロードしてみてください。次のように一覧が空に戻ります。

![](/images/js-task-tutorial-eguchi244/6.js-task-storage/2026-10-14-20-33-46.png =650x)

**原因:** `tasks` 配列は、ページを開いている間だけメモリ上にあります。リロードすると `script.js` が最初から実行され直し、`let tasks = [];` で空の配列から始まるためです。

**解決策:** ブラウザに用意されている保存領域 `localStorage` に `tasks` を書き込んでおき、ページを開いたときに読み戻します。この章で増える流れは次のとおりです。

```
ページ読み込み時
  loadTasks()   ← localStorage から tasks を読み戻す   （この章で追加）
  render()

状態を変える操作のたび（追加・完了切り替え・削除）
  addTask() / toggleTask() / deleteTask()
  saveTasks()   ← tasks を localStorage に書き込む     （この章で追加）
  render()
```

# ②保存と読み込みの関数を書く
`toggleTask` の下に、保存用の `saveTasks` と読み込み用の `loadTasks` を追記します。

```js:script.js
// ==========================================
// localStorage 永続化
// ==========================================

/**
 * tasks配列をlocalStorageに保存する
 */
function saveTasks() {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
}

/**
 * localStorageからtasksを復元する。
 *
 * NOTE: データが存在しない、または壊れている場合は空配列にフォールバックする。
 * NOTE: 配列以外（未保存のnull、"abc" や {} など）はすべて空配列として扱う
 */
function loadTasks() {
  try {
    const stored = JSON.parse(localStorage.getItem(STORAGE_KEY));

    // 配列判定：配列はそのままtasks配列に代入, 配列以外のデータの場合は空配列にする
    tasks = Array.isArray(stored) ? stored : [];
  } catch (error) {
    // 保存データが壊れていた場合は空の状態から始める
    tasks = [];
    console.error(`予期しないエラー: ${error.name} ${error.message}`);
  }
}
```

## localStorage は文字列しか保存できない
`localStorage.setItem(キー, 値)` で保存し、`localStorage.getItem(キー)` で読み出します。ただし、保存できるのは**文字列だけ**です。配列やオブジェクトはそのままでは入れられないので、次の2つで変換します。

| 関数 | 変換 | 使う場面 |
|------|------|------|
| `JSON.stringify` | 配列・オブジェクト → JSON 文字列 | 保存するとき（`saveTasks`） |
| `JSON.parse` | JSON 文字列 → 配列・オブジェクト | 読み出すとき（`loadTasks`） |

たとえばタスクが1件なら、`localStorage` には次のような文字列が入ります。

```json
[{"id":"36b8f84d-...","title":"牛乳を買う","completed":false,"createdAt":"2026-10-14T11:33:45.000Z"}]
```

## try / catch ― 壊れたデータに備える
`localStorage` の中身は、開発者ツールから誰でも書き換えられます。JSON として正しくない文字列が入っていると、`JSON.parse` は**例外（エラー）**を投げ、そのままでは後ろの処理が実行されずアプリが起動できなくなります。

`try { ... } catch (error) { ... }` で囲むと、`try` の中で例外が起きたときに `catch` の中へ処理が移ります。ここでは空の配列から始め直し、何が起きたかを `console.error` で開発者ツールのコンソールに出しておきます。**外から来るデータは信用しない**、という考え方の実践です。

## Array.isArray ― 例外にならない不正なデータに備える
`try / catch` だけでは足りない場合があります。

- `'"abc"'` や `'{"a":1}'` は**正しい JSON なので例外を投げません**。そのまま `tasks` に入れると `tasks` が配列ではなくなり、直後の `render()` の `tasks.filter(...)` でエラーになります
- 一度も保存していないブラウザでは、`getItem` が `null` を返します。`JSON.parse(null)` も `null` を返すだけで、例外にはなりません

そこで `Array.isArray(stored)` で**配列かどうかまで確かめ**、配列でなければ空の配列から始めます。「例外が出ないこと」と「期待どおりのデータであること」は別物です。

# ③保存のタイミングを差し込む
状態が変わる操作（追加・削除・完了切り替え）のイベントハンドラーで、`render()` の**前**に `saveTasks()` を呼びます。差し込む場所は次の2か所です。

```js:script.js
function handleTaskSubmit(event) {
  // ...

  // タスクリストを作成・保存して描画する
  addTask(title);
  saveTasks(); // 追加
  render();

  // ...
}
```

```js:script.js
function handleTaskListClick(event) {
  // ...

  // actionに応じた状態更新を実行する
  if (action === 'delete') {
    deleteTask(id);
  } else if (action === 'toggle') {
    toggleTask(id);
  } else {
    return;
  }

  // タスクリストを保存して再描画する
  saveTasks(); // 追加
  render();
}
```

`handleFilterClick` には `saveTasks()` を**入れません**。`filter` は「今どう見ているか」という一時的な画面の状態で、守るべきデータではないからです。リロードしたら「すべて」タブから始まって困ることはありません。**保存すべき状態と、消えてよい状態を区別する**感覚を持っておきましょう。

# ④起動時に読み込む
ファイルの末尾の初期描画を、次のように書き換えます。

```js:script.js
// ==========================================
// 初期描画
// ==========================================
loadTasks();
render();
```

起動時の流れは「`localStorage` から `tasks` を読み戻す → その状態で初回の描画」です。入門03から変わらない「状態 → 画面」の流れの前に、読み込みが1段加わっただけです。

:::details script.js の全体コード
```js:script.js
/* ==========================================
 * タスク管理アプリ（Vanilla JS）
 * 状態管理・DOM描画・localStorage永続化
 * ========================================*/

// ==========================================
// 型定義
// ==========================================

/**
 * @typedef {Object} Task
 * @property {string} id
 * @property {string} title
 * @property {boolean} completed
 * @property {string} createdAt
 */

// ==========================================
// DOM要素
// ==========================================
const taskForm      = document.getElementById('taskForm');
const taskInput     = document.getElementById('taskInput');
const filterButtons = document.querySelectorAll('.filter');
const taskList      = document.getElementById('taskList');
const taskCount     = document.getElementById('taskCount');

// ==========================================
// 状態変数
// NOTE: 単一の真実のソース（Single Source of Truth）
// ==========================================
/** @type {Task[]} */
let tasks  = [];    // タスク配列
let filter = 'all'; // 'all' | 'active' | 'completed'

// ==========================================
// localStorage Key
// ==========================================
const STORAGE_KEY = 'tasks';

// ==========================================
// タスク操作
// ==========================================

/**
 * 新しいタスクを作成してtasks配列に追加する
 *
 * @param {string} title - タスクのタイトル
 */
function addTask(title) {
  tasks.push({
    id: crypto.randomUUID(),
    title,
    completed: false,
    createdAt: new Date().toISOString(),
  });
}

/**
 * 指定ID以外のタスクでtasks配列を作り直す
 *
 * NOTE: 指定IDのタスクを削除すると同義です
 * @param {string} id - タスクのUUID
 */
function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
}

/**
 * タスクの完了状態を反転して更新する
 *
 * @param {string} id - タスクのUUID
 */
function toggleTask(id) {
  // 指定IDのタスクを取得
  const task = tasks.find((t) => t.id === id);

  // タスクの完了状態を反転する
  // NOTE: undefined対策 - タスクを取得できない時は状態更新しない
  if (task) {
    task.completed = !task.completed;
  }
}

// ==========================================
// localStorage 永続化
// ==========================================

/**
 * tasks配列をlocalStorageに保存する
 */
function saveTasks() {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
}

/**
 * localStorageからtasksを復元する。
 *
 * NOTE: データが存在しない、または壊れている場合は空配列にフォールバックする。
 * NOTE: 配列以外（未保存のnull、"abc" や {} など）はすべて空配列として扱う
 */
function loadTasks() {
  try {
    const stored = JSON.parse(localStorage.getItem(STORAGE_KEY));

    // 配列判定：配列はそのままtasks配列に代入, 配列以外のデータの場合は空配列にする
    tasks = Array.isArray(stored) ? stored : [];
  } catch (error) {
    // 保存データが壊れていた場合は空の状態から始める
    tasks = [];
    console.error(`予期しないエラー: ${error.name} ${error.message}`);
  }
}

// ==========================================
// DOM 描画
// ==========================================

/**
 * タスクリストのli要素を作成する
 *
 * @param {Task} task - タスク
 * @returns {HTMLLIElement}　li要素のタスクリスト
 */
function createTaskElement(task) {
  // li要素を作成する
  const li = document.createElement('li');
  li.className = task.completed ? 'task-item completed' : 'task-item';

  // checkbox要素を作成する
  const checkbox = document.createElement('input');
  checkbox.type = 'checkbox';
  checkbox.checked = task.completed;
  checkbox.dataset.id = task.id;
  checkbox.dataset.action = 'toggle';

  // タイトルのspan要素を作成する
  const title = document.createElement('span');
  title.className = 'task-title';
  title.textContent = task.title; // XSS対策(textContent使用)

  // 削除用のbtn要素を作成する
  const deleteBtn = document.createElement('button');
  deleteBtn.type = 'button';
  deleteBtn.className = 'btn btn-delete';
  deleteBtn.textContent = '削除';
  deleteBtn.dataset.id = task.id;
  deleteBtn.dataset.action = 'delete';

  // li要素に各要素をまとめて追加する
  li.append(checkbox, title, deleteBtn);
  return li;
}

/**
 * 現在の状態（tasks, filter）に基づいて画面を再描画する
 *
 * 以下の処理をすべて実行します：
 * 1. 選択中のフィルター（all/active/completed）に応じたタスクの絞り込みとリスト描画
 * 2. フッター（残り件数 / 総件数）のテキスト更新
 * 3. フィルターボタンのアクティブ状態（CSSクラス）の切り替え
 */
function render() {
  // フィルタに応じた絞り込みでtasks配列を作り直す
  const visibleTasks = tasks.filter((task) => {
    if (filter === 'active') return !task.completed;
    if (filter === 'completed') return task.completed;
    return true;
  });

  // タスクリストの再描画（空にしてから生成し直す）
  taskList.innerHTML = '';
  visibleTasks.forEach((task) => {
    taskList.appendChild(createTaskElement(task));
  });

  // フッター（残り件数 / 総件数）
  const remaining = tasks.filter((task) => !task.completed).length;
  taskCount.textContent = `残り ${remaining} 件 / 全 ${tasks.length} 件`;

  // フィルタータブのアクティブ状態（CSSクラス）の切り替え
  filterButtons.forEach((btn) => {
    btn.classList.toggle('active', btn.dataset.filter === filter);
  });
}

// ==========================================
// イベントハンドラー
// ==========================================

/**
 * タスク入力欄の送信イベントを処理する
 *
 * @param {SubmitEvent} event - フォーム送信のイベントオブジェクト
 */
function handleTaskSubmit(event) {
  // Formの規定動作を止める（SPA用のページリロード対策）
  event.preventDefault();

  // バリデーション
  // NOTE: 前後の空白を除去した結果が空文字なら追加しない
  const title = taskInput.value.trim();
  if (title === '') return;

  // タスクリストを作成・保存して描画する
  addTask(title);
  saveTasks();
  render();

  // タスク入力欄を空にしてフォーカスする
  taskInput.value = '';
  taskInput.focus();
}

/**
 * タスクリスト内のクリックイベントを処理する（イベント移譲）
 *
 * NOTE: タスクリストの削除・完了切り替えを action に応じて実行する
 * @param {MouseEvent} event - クリックイベントのオブジェクト
 */
function handleTaskListClick(event) {
  // クリックされた要素の data-id と data-action を取得
  const { id, action } = event.target.dataset;

  // idが存在しない場合は何もしない
  if (!id) return;

  // actionに応じた状態更新を実行する
  if (action === 'delete') {
    deleteTask(id);
  } else if (action === 'toggle') {
    toggleTask(id);
  } else {
    return;
  }

  // タスクリストを保存して再描画する
  saveTasks();
  render();
}

/**
 * フィルターボタンのクリックイベントを処理する
 *
 * @param {MouseEvent} event - クリックイベントのオブジェクト
 */
function handleFilterClick(event) {
  // クリックされたボタンの data-filter を取得
  const nextFilter = event.target.dataset.filter;

  // data-filterが取得できない場合は何もしない
  if (!nextFilter) return;

  // 状態（filter）を更新
  filter = nextFilter;

  // 画面を再描画する
  render();
}

// ==========================================
// イベントリスナー
// ==========================================

// --- タスク入力欄 ---
taskForm.addEventListener('submit', handleTaskSubmit);

// --- タスクリストの削除・完了切り替え（イベント移譲）---
taskList.addEventListener('click', handleTaskListClick);

// --- フィルターボタンの切り替え（各ボタンに個別バインド） ---
filterButtons.forEach((btn) => {
  btn.addEventListener('click', handleFilterClick);
});

// ==========================================
// 初期描画
// ==========================================
loadTasks();
render();
```
:::

# ⑤動きを追いかけてみる
タスクを2件追加し、1件を完了にしてからリロードすると何が起きるかを追ってみます。

1. **タスクを追加** → `handleTaskSubmit` → `addTask` で `tasks` が変わる → `saveTasks` で `localStorage` の `tasks` キーに配列全体が JSON 文字列で書き込まれる → `render()`
2. **1件を完了にする** → `handleTaskListClick` → `toggleTask` → `saveTasks` で、完了の状態を含めて書き込み直される → `render()`
3. **リロード** → `script.js` が最初から実行され、`tasks` はいったん空の配列になる → 末尾の `loadTasks()` が `localStorage` から JSON 文字列を読み出し、`JSON.parse` で配列に戻して `tasks` に入れる → `render()` が2件（うち1件は完了）を描く

保存（`saveTasks`）は「状態を変えた直後」、読み込み（`loadTasks`）は「起動時の1回だけ」です。どちらも `render()` には手を入れていません。

# ⑥動作確認
次の動作ができれば、タスク管理アプリの完成です。

- [✔] タスクを追加して**リロード**しても一覧が復元される
- [✔] 完了状態・削除もリロード後に反映されている
- [✔] 開発者ツール（F12）→「Application」→「Local Storage」に `tasks` キーがあり、JSON 文字列が入っている
- [✔] その JSON を手で壊して（例: 先頭の `[` を消して）リロードしても、エラーにならず空の状態で起動する
- [✔] 別のタブで同じページを開くと、同じタスク一覧が見える（`localStorage` は同じオリジンなら共有される）
