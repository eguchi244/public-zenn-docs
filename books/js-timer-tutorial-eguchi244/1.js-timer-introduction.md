# はじめに
この書籍は、フレームワークを使わない素の JavaScript（Vanilla JS）で「カウントダウンタイマー / ストップウォッチ」を作ることを目的としています。

タイマーは題材としてシンプルですが、JavaScript の基礎が詰まっています。

- `setInterval` / `clearInterval` による時間の制御
- 状態（残り時間・経過時間）と画面表示の同期
- ボタン操作をきっかけに処理が動く「イベント駆動」の考え方
- `async/await` を使った非同期処理

フレームワークを使うと、これらの多くは裏側で自動的に処理されます。最初に素の JavaScript で一度作っておくと、フレームワークが何を肩代わりしているのかが見えるようになります。

:::message
この書籍は、コードを読み慣れていない方でも進められるように書いています。コードは役割ごとに分けて掲載し、それぞれの直後に「何をしているか・なぜ必要か」を説明します。
:::

# ①作るもの
ブラウザ単体で動作するタイマーアプリです。カウントダウンタイマーとストップウォッチの2つの機能を、タブで切り替えて1画面で使えます。

```
+-------------------------------+
|  [カウントダウン] [ストップウォッチ]  ← タブ切り替え
+-------------------------------+
|                               |
|     [00] : [00] : [00]        | ← 時間入力欄
|                               |
|        00 : 00 : 00           | ← HH:MM:SS 表示
|                               |
|  ⏰ 時間になりました！          | ← タイムアップ通知
|                               |
|   [開始]  [停止]  [リセット]    |
|                               |
|  (ストップウォッチ時のみ)       |
|   [ラップ]                     |
|   - 00:01:23                  |
|   - 00:02:47                  |
+-------------------------------+
```

## 機能一覧
### カウントダウンタイマー
| # | 要件 |
|---|------|
| F-01 | 時・分・秒を個別に入力してカウントダウン時間を設定できる |
| F-01a | 入力できる範囲は **時: 0〜99 / 分: 0〜59 / 秒: 0〜59**（設定可能な最大値は `99:59:59`） |
| F-01b | 範囲外の値・空欄が入力された場合はエラーとせず、範囲内へ自動補正（クランプ）して入力欄へ反映する |
| F-01c | 入力値の変更は確定操作を必要とせず、キー入力のたびに残り時間表示へ即時反映される |
| F-02 | 開始ボタンを押すと1秒ごとに残り時間が減算される |
| F-03 | 一時停止ボタンを押すと計測が停止し、再度開始ボタンで再開できる |
| F-04 | リセットボタンを押すと設定時間に戻る |
| F-05 | 残り時間が0になったとき、アラート（音またはUI通知）を発生させる |
| F-05a | 音声再生はブラウザの自動再生ポリシーにより `AudioContext` が `suspended` 状態になる場合があるため、`resume()` の完了を待ってから再生する |

### ストップウォッチ
| # | 要件 |
|---|------|
| F-06 | 開始ボタンを押すと経過時間の計測を開始する |
| F-07 | 停止ボタンを押すと計測を一時停止し、再開できる |
| F-08 | リセットボタンを押すと経過時間を 00:00:00 に戻す |
| F-09 | ラップボタンを押すとその時点の経過時間をラップ一覧に追記する |

### 共通
| # | 要件 |
|---|------|
| F-10 | 時間表示は `HH:MM:SS` 形式で行う |
| F-11 | カウントダウンとストップウォッチはタブで切り替えられる |

## 非機能要件
| # | 要件 |
|---|------|
| NF-01 | 外部ライブラリ・フレームワーク不使用（Vanilla JS のみ） |
| NF-02 | モバイルブラウザでも表示が崩れないこと（レスポンシブ対応） |
| NF-03 | ページリロード時にタイマー状態はリセットされて構わない（永続化不要） |

# ②学習目標
この書籍を終えると、次のことができるようになります。

- `setInterval` / `clearInterval` によるタイマー制御を理解する
- タイマーIDの保持と停止処理を正確に実装できる
- DOM操作（表示更新・クラス切り替え）の基礎を習得する
- シンプルな状態管理（実行中 / 停止中 / リセット済み）をコードで表現できる
- `async/await` と `Promise` を返すブラウザAPI（`AudioContext.resume()`）を用いた非同期処理の基礎を理解する

# ③進め方
3つのフェーズに分けて、段階的にタイマーアプリを完成させます。

| 章 | フェーズ | 内容 | 習得する概念 |
|----|----------|------|------------|
| 入門03 | Phase 1 | シンプルなストップウォッチ | `setInterval` / DOM操作 / 3状態管理 |

# ④開発環境
## 技術スタック
| 項目 | 内容 |
|------|------|
| 言語 | HTML5 / CSS3 / JavaScript（ES6+） |
| 実行環境 | ブラウザ（Chrome 最新版を基準） |
| 開発ツール | VS Code + Live Server 拡張 |

外部ライブラリやビルドツールは使いません。ブラウザだけで動作するので、仮想環境やパッケージのインストールも不要です。

## VS Code と Live Server を用意する
VS Code と Live Server 拡張機能を使うと、ファイルを保存するたびにブラウザが自動でリロードされて便利です。Windows の場合は、PowerShell で次のコマンドを実行するとインストールできます。

```powershell:PowerShell
winget install Microsoft.VisualStudioCode
code --install-extension ritwickdey.LiveServer
```

:::message
`code` コマンドが見つからない場合は、VS Code をインストールしたあとにターミナルを開き直してください。
:::

## 作業フォルダを作る
任意の場所に作業フォルダ（例: `js-timer`）を作り、VS Code で開きます。この書籍では、このフォルダに次の3つのファイルを作っていきます。

```
js-timer/
├── index.html   # マークアップ（画面の構造）
├── style.css    # スタイル（見た目）
└── script.js    # タイマーロジック・DOM操作
```

起動するときは、VS Code で `index.html` を右クリック →「Open with Live Server」を選びます。Live Server を使わない場合は、`index.html` をブラウザで直接開いても動作します。

## CSS について
この書籍は JavaScript の学習に集中するため、CSS は完成版の `style.css` をそのまま使います。下記からダウンロードして、`index.html` と同じフォルダに置いてください。

https://github.com/eguchi244/JS-Timer-Tutorial-PJ/blob/main/style.css

:::message
CSS を自分で書きたい場合も、次のクラスだけは必須です。タブ切り替え・通知・ラップ一覧の表示/非表示をこのクラスで制御しているため、無いと入門04以降の動作確認ができません。

```css:style.css
.hidden {
  display: none;
}
```
:::
