# カウントダウンとドリフト補正
第4章では、入門03のストップウォッチに「カウントダウンモード」を追加します（Phase 2）。その前に、入門03の実装が抱えている問題に気づくところから始めます。

# 今回の目標物
- タブで「カウントダウン」と「ストップウォッチ」を切り替えられる
- カウントダウンは時・分・秒を入力して開始でき、0 になると通知が表示される
- 長時間動かしても時間がずれない

# ①入門03の問題を体験する
入門03のストップウォッチを**5分以上**動かしてみてください。スマートフォンのタイマーと比較すると、少しずれていることがあります。

**原因:** `setInterval(tick, 1000)` は「1000ms ごとに呼ぶ」という命令ですが、JavaScript のイベントループの都合で、実際には 1010ms や 1020ms かかることがあります。その誤差が積み重なって、ずれが生じます。

```
理想: 1000ms → 2000ms → 3000ms → ...
実際: 1012ms → 2031ms → 3058ms → ... （少しずつ遅れる）
```

**解決策:** `elapsedSec++` をやめて、`Date.now()` を使って「開始時刻からの経過時間」を毎回計算します。

## data-mode 属性
タブボタンに `data-mode="countdown"` のようなカスタム属性を付けます。JavaScript から `button.dataset.mode` で読み取り、どのモードに切り替えるかを判断します。

# ③state オブジェクトへ移行する
この章では `script.js` を最初から書き直します。ただし、**プログラムの動き方そのものは入門03と同じ**です。読み込み時に準備してイベントリスナーを予約し、待機状態に入り、あとはユーザーの操作をきっかけに関数が呼ばれます。変わるのは「管理する状態が増えること」と「時間の計算方法」の2点です。

先に、この章を終えた時点の全体フローを示します。「← 新規 / 変更」と注記した行が、入門03から増えた・変わった部分です。

```
ページ読み込み時（1回だけ）
  state の初期化 → DOM参照の取得 → 関数定義 → リスナー登録 → 初期描画

以降はユーザーの操作がきっかけ:
  [タブをクリック]     → switchMode()   ← 新規: モードを切り替えて状態を全リセット
  [時/分/秒を入力]     → onInputChange() ← 新規: 目標秒数を計算し直して表示に反映
  [開始をクリック]     → startTimer()    ← 変更: 開始時刻(startTime)を記録してから tick を予約
  （以降500msごと）    → tick()          ← 変更: 「現在時刻 − 開始時刻」で経過/残り秒数を計算
  [停止をクリック]     → stopTimer()
  [リセットをクリック] → resetTimer()
```

カウントダウンが加わると、管理する変数が増えます（`mode`・`targetSec`・`remainingSec` など）。入門03のようにバラバラな変数で持つより、1つのオブジェクトにまとめたほうが「これらは全部このアプリの状態だ」という関係が分かりやすくなります。

```js:script.js
/* ==========================================
 * 状態変数
 * ========================================*/
const state = {
  mode        : 'countdown', // 'countdown' | 'stopwatch'
  status      : 'idle',      // 'idle' | 'running' | 'paused'
  intervalId  : null,        // setInterval の返り値
  startTime   : null,        // Date.now() 基準点（ドリフト補正用, 一時停止のたびに巻き戻しの再計算）
  elapsedSec  : 0,           // ストップウォッチ用（経過時間）
  remainingSec: 0,           // カウントダウン用（残り時間）
  targetSec   : 0,           // カウントダウン設定値（リセット基準）
};

/* ==========================================
 * DOM参照
 * ========================================*/
const countdownInput = document.getElementById('countdownInput');
const inputH         = document.getElementById('inputH');
const inputM         = document.getElementById('inputM');
const inputS         = document.getElementById('inputS');
const display        = document.getElementById('display');
const notification   = document.getElementById('notification');
const btnStart       = document.getElementById('btnStart');
const btnStop        = document.getElementById('btnStop');
const btnReset       = document.getElementById('btnReset');
```

各フィールドの役割は次のとおりです。以後は `state.status` のように「`state.` を付けて」読み書きします。

| フィールド | 役割 |
|-----------|------|
| `mode` | 今どちらのタブか（`'countdown'` / `'stopwatch'`） |
| `status` | 入門03と同じ3状態（`'idle'` / `'running'` / `'paused'`） |
| `intervalId` | `tick` の予約番号（入門03と同じ） |
| `startTime` | 開始ボタンを押した**時刻**の記録。④のドリフト補正の基準点になる |
| `elapsedSec` | ストップウォッチの経過秒数 |
| `remainingSec` | カウントダウンの残り秒数 |
| `targetSec` | 入力欄でセットした目標秒数（カウントダウンの開始値） |

DOM参照には、新しく追加した通知エリア（`notification`）とカウントダウン入力欄（`countdownInput`・`inputH/M/S`）が増えています。

# ④ドリフト補正を組み込んだ tick を実装する
入門03との違いは、`elapsedSec++` の代わりに `Date.now() - startTime` で計算する点です。

```js:script.js
/**
 * タイマーの状態を1秒分進めて表示へ反映する
 *
 * - countdownモード: 残り時間(remainingSec)を再計算し、0以下になったら
 *   タイマーを停止して通知を表示する
 * - stopwatchモード: 経過時間(elapsedSec)を再計算する
 *
 * NOTE: setInterval から1秒ごとに呼ばれる
 */
function tick() {
  if (state.mode === 'countdown') {
    // 残り時間 = カウントダウン設定値 - 経過時間（ドリフト補正: 開始時刻からの差分で計算）
    state.remainingSec = state.targetSec - Math.floor((Date.now() - state.startTime) / 1000);

    // カウントダウン完了時の処理
    if (state.remainingSec <= 0) {
      // タイマーのクリア
      clearInterval(state.intervalId);
      // 状態の更新
      state.intervalId = null;
      state.remainingSec = 0;
      state.status = 'paused';
      notification.classList.remove('hidden');
      // UI更新
      updateDisplay();
      updateButtons();
      // tick() の処理を終了
      return;
    }

  } else {
    // 経過時間 = 現在時刻 - 開始時刻（ドリフト補正: 開始時刻からの差分で計算）
    state.elapsedSec = Math.floor((Date.now() - state.startTime) / 1000);
  }
  // UI更新
  updateDisplay();
}
```

## tick の構造 ― モードによって仕事が変わる
- **ストップウォッチのとき（`else` 側）:** 「現在時刻 − 開始時刻」をミリ秒で求め、1000 で割って秒に直したものを経過秒数にします。入門03の `elapsedSec++` の置き換えで、毎回現在時刻から計算し直すため誤差が積み重なりません
- **カウントダウンのとき:** 同じ計算で「経過秒数」を出し、それを目標秒数 `targetSec` から引いた残りを `remainingSec` にします。残りが 0 以下になったら、タイムアップ処理に入ります

## タイムアップ時に起きること
`if (state.remainingSec <= 0)` の中を、上から順に追います。

1. `clearInterval` で `tick` の予約を取り消す。これでカウントが止まる
2. `remainingSec` を 0 に揃えて表示を `00:00:00` に更新する（計算結果が −1 などになっていても 0 と表示するため）
3. `status` を `'paused'` に変え、通知（「時間になりました！」）の `hidden` クラスを外して表示し、ボタンの有効/無効を更新する
4. `return` で関数を抜ける。関数末尾の `updateDisplay()` を二重に呼ばないためです

## startTime の仕組み
```
開始ボタン押下時:
  state.startTime = Date.now()   // 例: 1000000000000

10秒後の tick():
  Date.now() = 1000000010000
  elapsedSec = (1000000010000 - 1000000000000) / 1000 = 10  ← 誤差ゼロ
```

## 一時停止後の再開
停止中に20秒経過してから再開した場合、`startTime` をそのまま使うと「停止中の20秒」も計測されてしまいます。そのため、再開時に「既に経過した分を折り込んだ起点（再計算後の `startTime`）」を設定します。

```
elapsedSec が 30 の時点で停止 → 再開
startTime = Date.now() - 30 * 1000
→ 再開後の tick() で Date.now() - startTime ≈ 30秒 → 続きから計測できる
```

再開時の再計算は、⑤の `startTimer` で実装します。

# ⑤その他の関数を実装する
残りの関数を「表示系」→「タイマー操作系」の順に実装します。入門03で書いたものと役割は同じなので、**入門03から何が変わったか**に注目しながら読んでください。

## 表示系 ― formatTime / updateDisplay / updateButtons
```js:script.js
/**
 * 秒数を HH:MM:SS 文字列に変換する
 *
 * @param {number} totalSec - 変換する秒数（0以上の整数を想定。負値・小数は丸めていない）
 * @returns {string} `00:00:00` 形式の文字列（各桁は2桁に0埋め）
 */
function formatTime(totalSec) {
  // マイナス値の混入防止
  // NOTE: カウントダウンでは計算のタイミングによって一瞬だけ負の値になることがあるため、
  //       0 未満は 0 に切り上げてから表示する
  const sec = Math.max(0, Math.floor(totalSec));

  const h = Math.floor(sec / 3600);
  const m = Math.floor((sec % 3600) / 60);
  const s = sec % 60;
  return [h, m, s].map(v => String(v).padStart(2, '0')).join(':');
}
```

**formatTime の変更点:** 入門03との違いとして `Math.max(0, Math.floor(totalSec))` が加わっています。カウントダウンでは計算のタイミングによって一瞬だけ負の値になることがあるため、0 未満は 0 に切り上げてから表示します。

```js:script.js
/**
 * 現在のモードに応じた時間を HH:MM:SS 形式で表示欄へ書き出す
 *
 * - countdownモード: カウントダウン用（残り時間）を表示
 * - stopwatchモード: ストップウォッチ用（経過時間）を表示
 */
function updateDisplay() {
  // 現在のモードに応じた時間を取得して表示
  const sec = state.mode === 'countdown' ? state.remainingSec : state.elapsedSec;
  display.textContent = formatTime(sec);
}
```

**updateDisplay の変更点 ― どちらの秒数を表示するか:** モードが2つになったため、「カウントダウンなら残り秒数、ストップウォッチなら経過秒数」と、表示する値を選ぶ分岐が入りました。ここで使っている `state.mode === 'countdown' ? state.remainingSec : state.elapsedSec` は**三項演算子 `条件 ? A : B`**（条件が真なら A、偽なら B を返す式）で、`if` / `else` の分岐を1行の式として書けます。

```js:script.js
/**
 * 現在の状態に応じて3つのボタンの活性・非活性を切り替える
 */
function updateButtons() {
  // 各状態を定義する
  const running  = state.status === 'running';
  const idle     = state.status === 'idle';
  const noTarget = state.mode === 'countdown' && state.targetSec === 0; // カウントダウン時の時間未設定

  // ボタンの活性・非活性を切り替える
  btnStart.disabled = running || noTarget;
  btnStop.disabled  = !running;
  btnReset.disabled = idle;
}
```

**updateButtons の変更点 ―「時間未セットなら開始できない」:** 新しい条件 `noTarget` が加わりました。カウントダウンモードで目標秒数が 0（= まだ時間をセットしていない）のときは、開始ボタンを無効のままにします。「状態を見てボタンを決める」という入門03のルールはそのままで、見る状態が増えただけです。

## タイマー操作系 ― startTimer / stopTimer / resetTimer
```js:script.js
/**
 * タイマーを開始・再開する
 */
function startTimer() {
  // カウントダウンで時間未指定なら何もしない
  if (state.mode === 'countdown' && state.targetSec === 0) return;

  // モードに応じた開始時間の記録（再開時の開始日時の再計算にも対応）
  if (state.mode === 'countdown') {
    // 開始時間 = 現在時間 - (カウントダウン設定値 - カウントダウン用残り時間)
    state.startTime = Date.now() - (state.targetSec - state.remainingSec) * 1000;
  } else {
    // 開始時間 = 現在時間 - ストップウォッチ用（経過時間）
    state.startTime = Date.now() - state.elapsedSec * 1000;
  }

  // タイマーを開始・再開する
  state.intervalId = setInterval(tick, 500);
  // 状態更新
  state.status = 'running';
  // UI更新
  notification.classList.add('hidden'); // 通知タグを非表示に変更
  updateButtons();
}
```

上から順に読みます。

1. **ガード:** カウントダウンで時間未セットなら何もせず抜ける（`updateButtons` でボタンは無効化済みだが、二重の安全策）
2. **開始時刻の記録:** ここが④で説明した「既に経過した分を折り込んだ起点」の実装です。初回スタート時は `remainingSec === targetSec`（経過ゼロ）なので `startTime = Date.now()` と同じ意味になり、一時停止からの再開時は経過分だけ過去にずらした時刻になります。ストップウォッチ側の `Date.now() - state.elapsedSec * 1000` も同じ考え方です
3. `tick` を **500ms ごと**に予約し、`status` を `'running'` にする
4. 表示されているかもしれない通知を隠し、ボタンを更新する

:::message
**setInterval の間隔を 500ms にする理由:** 1000ms にすると、秒が変わった瞬間を最大1秒見逃します。500ms にすることで、最大0.5秒以内に画面に反映されます。`tick` の中は「毎回現在時刻から計算」なので、呼ぶ回数が増えても時間がずれることはありません。
:::

```js:script.js
/**
 * タイマーを一時停止する（経過秒数は保持したままタイマーだけを止める）
 */
function stopTimer() {
  // タイマーのクリア
  clearInterval(state.intervalId);
  // 状態の更新
  state.intervalId = null;
  state.status = 'paused';
  // UI更新
  updateButtons();
}
```

**stopTimer:** 構造は入門03と同じ「予約取り消し → 状態変更 → 画面反映」です。状態変数に `state.` を付けています。

```js:script.js
/**
 * タイマーを止めて初期状態(idle)へ戻す
 */
function resetTimer() {
  // タイマーのクリア
  clearInterval(state.intervalId);
  // 状態の一括リセット
  state.intervalId = null;
  state.startTime = null;
  state.elapsedSec = 0;
  state.remainingSec = state.targetSec;
  state.status = 'idle';
  // UI更新
  notification.classList.add('hidden');
  updateDisplay();
  updateButtons();
}
```

**resetTimer:** 構造は入門03と同じ「予約取り消し → 状態変更 → 画面反映」です。`remainingSec` を 0 ではなく `targetSec` に戻している点に注目してください。リセット後の表示を「セットした時間」に戻すためです（ストップウォッチなら `elapsedSec = 0` で `00:00:00` に戻ります）。

# ⑥タブ切り替えとカウントダウン入力を実装する
最後に、この章で新しく増えた2つのユーザー操作に対応します。実装の前に「操作されたら何が起きるべきか」を整理しておきます。

- **タブをクリックしたとき:** 計測を止めて全状態をリセットし、モードを切り替え、そのモード用の画面（入力欄の表示/非表示、タブの見た目）にする
- **時/分/秒を入力したとき:** 入力値から目標秒数 `targetSec` を計算し直し、表示とボタン（時間がセットされたら開始を有効に）へ反映する

## タブ切り替え ― switchMode
```js:script.js
/**
 * タイマーの動作モードを切り替える
 *
 * NOTE: モード切り替え時は必ずタイマーを停止・状態初期化してUI描写を更新する
 * @param {string} mode - 切り替え先のモード識別子
 */
function switchMode(mode) {
  // 現在と同じモードの場合はなにもしない
  if (state.mode === mode) return;

  // 状態の更新
  state.mode = mode;

  // タイマーのクリア
  clearInterval(state.intervalId);

  // 状態の一括リセット
  state.intervalId = null;
  state.startTime = null;
  state.elapsedSec = 0;
  state.remainingSec = 0;
  state.targetSec = 0;
  state.status = 'idle';

  // 通知タグUIの更新
  notification.classList.add('hidden');

  // 現在選択されているタブだけに active を付与する
  document.querySelectorAll('.tab').forEach(t => {
    t.classList.toggle('active', t.dataset.mode === mode);
  });

  // カウントダウン選択時の初期値設定とUI描写をする
  // NOTE: ストップウォッチ選択時はカウントダウン設定欄は非表示にする
  if (state.mode === 'countdown') {
    countdownInput.classList.remove('hidden');
    inputH.value = 0;
    inputM.value = 0;
    inputS.value = 0;
  } else {
    countdownInput.classList.add('hidden');
  }

  // 画面・ボタンUIの更新
  updateDisplay();
  updateButtons();
}
```

上から順に読みます。

1. **ガード:** 今と同じタブをクリックされたときは何もしない
2. `state.mode` を切り替える
3. **全リセット:** 計測中でもタイマーの予約を取り消し、時間・状態をすべて初期値に戻します。「タブを切り替えたら前のモードの計測は破棄する」という仕様を、ここで実現しています
4. **タブの見た目:** すべてのタブ（`querySelectorAll('.tab')`）を順に見て、クリックされたモードのタブにだけ `active` クラスを付けます
5. **モード別の画面:** カウントダウンなら入力欄を表示して 0 に戻し、ストップウォッチなら入力欄ごと隠します
6. 仕上げに、表示とボタンを状態から作り直します

:::message
**`classList.toggle(クラス名, 真偽値)` ― 2引数の toggle:** 引数1つの `toggle` は「あれば外す・なければ付ける」ですが、2つ目に真偽値を渡すと「真なら付ける・偽なら外す」という明示的な切り替えになります。ここでは `t.dataset.mode === mode` の比較結果で、選択されたタブにだけ `active` クラスが付くようにしています。
:::

## 時間入力 ― onInputChange
```js:script.js
/**
 * カウントダウン入力欄の変更イベントハンドラ
 *
 * NOTE: カウントダウン入力欄の値を範囲補正して状態とUIを更新する
 */
function onInputChange() {
  // 計測中・一時停止中は何もできないようにする
  if (state.status !== 'idle') return;

  /**
   * カウントダウン入力欄の値を範囲補正する
   *
   * @param {HTMLInputElement} input - 補正対象のHTML入力要素
   * @param {number} min - 許容する最小値
   * @param {number} max - 許容する最大値
   * @returns {number} 補正後の数値
   */
  const clamp = (input, min, max) => {
    let v = parseInt(input.value, 10);
    // 空文字 or 最小値未満は最小値に補正
    if (isNaN(v) || v < min) v = min;
    // 最大値より大きければ最大値に補正
    if (v > max) v = max;
    // 補正した値をHTML属性に再設定する
    input.value = v;
    // 補正後の数値を返す
    return v;
  };

  // カウントダウンの入力値を取得
  const h = clamp(inputH, 0, 99);
  const m = clamp(inputM, 0, 59);
  const s = clamp(inputS, 0, 59);

  // カウントダウン設定値の状態を更新
  state.targetSec = h * 3600 + m * 60 + s;
  // カウントダウン残り時間の状態を更新
  state.remainingSec = state.targetSec;

  // 画面・ボタンUIの更新
  updateDisplay();
  updateButtons();
}
```

上から順に読みます。

1. **ガード:** 計測中・一時停止中は入力を無視します（`'idle'` のときだけ時間をセットできる）
2. **`clamp`（値の範囲補正）:** 入力欄の値は**常に文字列**なので `parseInt` で数値に変換し、空欄や範囲外（分に `75` など）は最小値・最大値に丸めます。補正後の値を入力欄にも書き戻すので、ユーザーには「勝手に直った」ように見えます
3. 時×3600 + 分×60 + 秒で**目標秒数を計算**し、`remainingSec` にも同じ値を入れます。これで表示が「セットした時間」になり、`updateButtons` の `noTarget` 条件が外れて開始ボタンが有効になります

:::message
**`parseInt(input.value, 10)` の第2引数:** 「10進数として解釈する」という指定（基数）です。省略しても通常は10進として扱われますが、明示しておくのが安全な習慣です。
:::

## イベントリスナー登録と初期描画
関数が出揃ったので、最後に「どの操作でどの関数を呼ぶか」を接続します。

```js:script.js
/* ==========================================
 * イベントリスナー
 * ========================================*/
// --- タブ ---
document.querySelectorAll('.tab').forEach(tab => {
  tab.addEventListener('click', () => switchMode(tab.dataset.mode));
});

// --- 開始・停止・リセットのボタン ---
btnStart.addEventListener('click', startTimer);
btnStop.addEventListener('click', stopTimer);
btnReset.addEventListener('click', resetTimer);

// --- カウントダウンの入力欄 ---
[inputH, inputM, inputS].forEach(input => {
  input.addEventListener('input', onInputChange);
  input.addEventListener('change', onInputChange);
});

/* ==========================================
 * 初期描画
 * ========================================*/
updateDisplay();
updateButtons();
```

**タブのリスナー:** 2つのタブそれぞれに、同じクリックリスナーを登録しています。`switchMode` には引数（どのモードか）を渡す必要があるため、`startTimer` のように関数名をそのまま渡すのではなく、`() => switchMode(tab.dataset.mode)` という「クリックされたら `switchMode` を引数付きで呼ぶ小さな関数」を作って渡しています。`tab.dataset.mode` は②で HTML に付けた `data-mode` 属性の値です。

**`'input'` と `'change'` の両方を登録する理由:**

- `input`: キーを押すたびに発火（即時反映）
- `change`: フォーカスが外れたときに発火（矢印キー操作後の Tab など）

両方登録することで、どちらの操作でも確実に反応します。同じ関数を2つのイベントに登録しても、`onInputChange` は「今の入力値から計算し直す」だけなので、何度呼ばれても結果は同じです。

:::details script.js の全体コード
```js:script.js
/* ==========================================
 * DOM参照
 * ========================================*/
const countdownInput = document.getElementById('countdownInput');
const inputH         = document.getElementById('inputH');
const inputM         = document.getElementById('inputM');
const inputS         = document.getElementById('inputS');
const display        = document.getElementById('display');
const notification   = document.getElementById('notification');
const btnStart       = document.getElementById('btnStart');
const btnStop        = document.getElementById('btnStop');
const btnReset       = document.getElementById('btnReset');

/* ==========================================
 * 状態変数
 * ========================================*/
const state = {
  mode        : 'countdown', // 'countdown' | 'stopwatch'
  status      : 'idle',      // 'idle' | 'running' | 'paused'
  intervalId  : null,        // setInterval の返り値
  startTime   : null,        // Date.now() 基準点（ドリフト補正用, 一時停止のたびに巻き戻しの再計算）
  elapsedSec  : 0,           // ストップウォッチ用（経過時間）
  remainingSec: 0,           // カウントダウン用（残り時間）
  targetSec   : 0,           // カウントダウン設定値（リセット基準）
};

/* ==========================================
 * ユーティリティ
 * ========================================*/

/**
 * 秒数を HH:MM:SS 文字列に変換する
 *
 * @param {number} totalSec - 変換する秒数（0以上の整数を想定。負値・小数は丸めていない）
 * @returns {string} `00:00:00` 形式の文字列（各桁は2桁に0埋め）
 */
function formatTime(totalSec) {
  // マイナス値の混入防止
  // NOTE: カウントダウンでは計算のタイミングによって一瞬だけ負の値になることがあるため、
  //       0 未満は 0 に切り上げてから表示する
  const sec = Math.max(0, Math.floor(totalSec));

  const h = Math.floor(sec / 3600);
  const m = Math.floor((sec % 3600) / 60);
  const s = sec % 60;
  return [h, m, s].map(v => String(v).padStart(2, '0')).join(':');
}

/**
 * タイマーの状態を1秒分進めて表示へ反映する
 *
 * - countdownモード: 残り時間(remainingSec)を再計算し、0以下になったら
 *   タイマーを停止して通知を表示する
 * - stopwatchモード: 経過時間(elapsedSec)を再計算する
 *
 * NOTE: setInterval から1秒ごとに呼ばれる
 */
function tick() {
  if (state.mode === 'countdown') {
    // 残り時間 = カウントダウン設定値 - 経過時間（ドリフト補正: 開始時刻からの差分で計算）
    state.remainingSec = state.targetSec - Math.floor((Date.now() - state.startTime) / 1000);

    // カウントダウン完了時の処理
    if (state.remainingSec <= 0) {
      // タイマーのクリア
      clearInterval(state.intervalId);
      // 状態の更新
      state.intervalId = null;
      state.remainingSec = 0;
      state.status = 'paused';
      notification.classList.remove('hidden');
      // UI更新
      updateDisplay();
      updateButtons();
      // tick() の処理を終了 
      return;
    }

  } else {
    // 経過時間 = 現在時刻 - 開始時刻（ドリフト補正: 開始時刻からの差分で計算）
    state.elapsedSec = Math.floor((Date.now() - state.startTime) / 1000);
  }
  // UI更新
  updateDisplay();
}

/* ==========================================
 * 画面・ボタン更新
 * ========================================*/

/**
 * 現在のモードに応じた時間を HH:MM:SS 形式で表示欄へ書き出す
 * 
 * - countdownモード: カウントダウン用（残り時間）を表示
 * - stopwatchモード: ストップウォッチ用（経過時間）を表示
 */
function updateDisplay() {
  // 現在のモードに応じた時間を取得して表示
  const sec = state.mode === 'countdown' ? state.remainingSec : state.elapsedSec;
  display.textContent = formatTime(sec);
}

/**
 * 現在の状態に応じて3つのボタンの活性・非活性を切り替える
 */
function updateButtons() {
  // 各状態を定義する
  const running  = state.status === 'running';
  const idle     = state.status === 'idle';
  const noTarget = state.mode === 'countdown' && state.targetSec === 0; // カウントダウン時の時間未設定

  // ボタンの活性・非活性を切り替える
  btnStart.disabled = running || noTarget;
  btnStop.disabled  = !running;
  btnReset.disabled = idle;
}

/* ==========================================
 * タイマー操作(開始・停止・リセット)
 * ========================================*/

/**
 * タイマーを開始・再開する
 */
function startTimer() {
  // カウントダウンで時間未指定なら何もしない
  if (state.mode === 'countdown' && state.targetSec === 0) return;

  // モードに応じた開始時間の記録（再開時の開始日時の再計算にも対応）
  if (state.mode === 'countdown') {
    // 開始時間 = 現在時間 - (カウントダウン設定値 - カウントダウン用残り時間)
    state.startTime = Date.now() - (state.targetSec - state.remainingSec) * 1000;
  } else {
    // 開始時間 = 現在時間 - ストップウォッチ用（経過時間）
    state.startTime = Date.now() - state.elapsedSec * 1000;
  }

  // タイマーを開始・再開する
  state.intervalId = setInterval(tick, 500);
  // 状態更新
  state.status = 'running';
  // UI更新
  notification.classList.add('hidden'); // 通知タグを非表示に変更
  updateButtons();
}

/**
 * タイマーを一時停止する（経過秒数は保持したままタイマーだけを止める）
 */
function stopTimer() {
  // タイマーのクリア
  clearInterval(state.intervalId);
  // 状態の更新
  state.intervalId = null;
  state.status = 'paused';
  // UI更新
  updateButtons();
}

/**
 * タイマーを止めて初期状態(idle)へ戻す 
 */
function resetTimer() {
  // タイマーのクリア
  clearInterval(state.intervalId);
  // 状態の一括リセット
  state.intervalId = null;
  state.startTime = null;
  state.elapsedSec = 0;
  state.remainingSec = state.targetSec;
  state.status = 'idle';
  // UI更新
  notification.classList.add('hidden');
  updateDisplay();
  updateButtons();
}

/* ==========================================
 * タブ切り替え(モード)
 * ========================================*/

/**
 * タイマーの動作モードを切り替える
 *
 * NOTE: モード切り替え時は必ずタイマーを停止・状態初期化してUI描写を更新する
 * @param {string} mode - 切り替え先のモード識別子
 */
function switchMode(mode) {
  // 現在と同じモードの場合はなにもしない
  if (state.mode === mode) return;

  // 状態の更新
  state.mode = mode;

  // タイマーのクリア
  clearInterval(state.intervalId);

  // 状態の一括リセット 
  state.intervalId = null;
  state.startTime = null;
  state.elapsedSec = 0;
  state.remainingSec = 0;
  state.targetSec = 0;
  state.status = 'idle';

  // 通知タグUIの更新　
  notification.classList.add('hidden');

  // 現在選択されているタブだけに active を付与する
  document.querySelectorAll('.tab').forEach(t => {
    t.classList.toggle('active', t.dataset.mode === mode);
  });

  // カウントダウン選択時の初期値設定とUI描写をする
  // NOTE: ストップウォッチ選択時はカウントダウン設定欄は非表示にする
  if (state.mode === 'countdown') {
    countdownInput.classList.remove('hidden');
    inputH.value = 0;
    inputM.value = 0;
    inputS.value = 0;
  } else {
    countdownInput.classList.add('hidden');
  }

  // 画面・ボタンUIの更新
  updateDisplay();
  updateButtons();
}

/* ==========================================
 * カウントダウン入力
 * ========================================*/

/**
 * カウントダウン入力欄の変更イベントハンドラ
 * 
 * NOTE: カウントダウン入力欄の値を範囲補正して状態とUIを更新する
 */
function onInputChange() {
  // 計測中・一時停止中は何もできないようにする
  if (state.status !== 'idle') return;

  /**
   * カウントダウン入力欄の値を範囲補正する
   *
   * @param {HTMLInputElement} input - 補正対象のHTML入力要素
   * @param {number} min - 許容する最小値
   * @param {number} max - 許容する最大値
   * @returns {number} 補正後の数値
   */
  const clamp = (input, min, max) => {
    let v = parseInt(input.value, 10);
    // 空文字 or 最小値未満は最小値に補正
    if (isNaN(v) || v < min) v = min;
    // 最大値より大きければ最大値に補正
    if (v > max) v = max;
    // 補正した値をHTML属性に再設定する
    input.value = v;
    // 補正後の数値を返す
    return v;
  };

  // カウントダウンの入力値を取得
  const h = clamp(inputH, 0, 99);
  const m = clamp(inputM, 0, 59);
  const s = clamp(inputS, 0, 59);

  // カウントダウン設定値の状態を更新
  state.targetSec = h * 3600 + m * 60 + s;
  // カウントダウン残り時間の状態を更新
  state.remainingSec = state.targetSec;

  // 画面・ボタンUIの更新
  updateDisplay();
  updateButtons();
}

/* ==========================================
 * イベントリスナー
 * ========================================*/
// --- タブ ---
document.querySelectorAll('.tab').forEach(tab => {
  tab.addEventListener('click', () => switchMode(tab.dataset.mode));
});

// --- 開始・停止・リセットのボタン ---
btnStart.addEventListener('click', startTimer);
btnStop.addEventListener('click', stopTimer);
btnReset.addEventListener('click', resetTimer);

// --- カウントダウンの入力欄 ---
[inputH, inputM, inputS].forEach(input => {
  input.addEventListener('input', onInputChange);
  input.addEventListener('change', onInputChange);
});

/* ==========================================
 * 初期描画
 * ========================================*/
updateDisplay();
updateButtons();
```

## この段階で残っている問題
カウントダウンが 0 になったあと、開始ボタンが**有効**になります。タイムアップ後に0秒のまま再スタートできてしまう状態です。また、タイマーの起動中にカウントダウンの入力ができてしまう状態にもなっています。これらは次の入門05で修正します。

# まとめ
ここまでの内容で、カウントダウンとストップウォッチの2つのモードを持つタイマーができました。

- `Date.now()` を基点にした計算で、長時間でもずれないタイマー（ドリフト補正）
- 関連する変数を1つにまとめる `state` オブジェクトの設計
- `dataset`・`classList.toggle` を使ったタブ切り替え
- 入力値の範囲補正（クランプ）

など、実際のアプリ開発でもよく使う技法を学ばれたと思います。
